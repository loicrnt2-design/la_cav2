CONNEXION AU PROJET

Firebase

Renseignez la configuration Web de votre projet. Elle sera enregistrée dans ce navigateur et utilisée par la boutique et l’administration.

La clé API Web identifie le projet, elle ne protège pas la base. N’utilisez jamais de clé privée ou de fichier de compte de service ici. Publiez d’abord les règles Firestore fournies.

Une configuration présente dans firebase-config.js reste active après effacement.
